مساعدك على الواتساب بـ Claude و Kapso

مساعد ذكي يرد على زبائنك، يحجز المواعيد وياخذ الطلبيات على رقم واتساب حقيقي، وإنت نايم. الخطوات كاملة مع البرومبت.

حساب Kapsoمن app.kapso.ai، فيه خطة مجانية
رقم واتسابرقمك للبزنس، أو Kapso يعطيك رقم جاهز أثناء الإعداد

الخطوات

  1. سوّ حساب في Kapso

    ادخل app.kapso.ai، سجّل وسوّ مشروع (Project) جديد.

  2. ثبّت الـ Kapso CLI وسجّل دخول

    افتح الـ Terminal واكتب:

    $ npm install -g @kapso/cli
$ kapso login
$ kapso status

    kapso status لازم يطلع لك اسم مشروعك. إذا ما طلع، شغّل kapso projects list ثم kapso projects use <project-id>.

  3. ركّب مهارات الواتساب في Claude Code

    بأمر واحد تنزل المهارات الرسمية من Kapso (ربط الواتساب، الأتمتة، التشخيص):

    $ npx skills add gokapso/agent-skills

  4. اربط رقم الواتساب

    $ kapso setup
# افتح الرابط اللي يطلع وكمّل الربط
$ kapso whatsapp numbers list

    آخر أمر يطلع لك الرقم المتصل. تقدر تربط رقمك أو تاخذ رقم جديد من Kapso.

  5. قول لـ Claude وش تريد بالضبط

    افتح Claude Code في مجلد جديد، وانسخ هذا البرومبت. عبّي اللي بين القوسين بمعلومات مشروعك:

    أبغى أبني مساعد واتساب لمشروعي باستخدام Kapso ومهارات Kapso المثبّتة (integrate-whatsapp و automate-whatsapp).

معلومات المشروع:
- اسم المشروع: [اكتب الاسم]
- نوع الخدمة: [مثلاً: صالون / عيادة / متجر]
- أوقات الدوام: [مثلاً: 9 الصبح لين 10 الليل، الجمعة إجازة]
- الخدمات والأسعار: [القائمة]
- لغة الرد: عربي بلهجة خليجية، وإنجليزي إذا العميل كتب إنجليزي

المطلوب:
1. تأكد إن Kapso CLI مسجّل (kapso status) وإن عندي رقم واتساب متصل. إذا ما في رقم، شغّل kapso setup وعطني الرابط.
2. ابني workflow يستقبل الرسائل الواردة ويرد عليها agent ذكي:
   - يجاوب أسئلة الزبائن من معلومات المشروع فوق بس، وما يألّف معلومات.
   - يحجز المواعيد: يسأل عن اليوم والوقت، يقترح أوقات متاحة، ويأكد الحجز برسالة واضحة.
   - ياخذ الطلبيات: يجمع اسم العميل والطلب والعنوان، ويرسل له ملخص يأكده.
   - إذا ما عرف الجواب أو العميل طلب يكلم موظف، يحوّل المحادثة لي.
3. احفظ الحجوزات والطلبيات في قاعدة بيانات Kapso.
4. جرّب الـ workflow برسالة تجريبية قبل التفعيل، واشرح لي وش سويت خطوة خطوة.

لا تطبع الـ API key أو أي secret في المحادثة.

  6. جرّبه

    أرسل رسالة للرقم من جوال ثاني: «السلام عليكم، عندكم موعد بكرة؟». لازم يرد عليك ويقترح أوقات. إذا في شي ما ضبط، قول لـ Claude وش صار وهو يصلّحه.

نصايح قبل ما تشغّله للزباين

  • الـ API key سر. لا تنشره ولا تحطه في كود ترفعه على GitHub.
  • جرّب على نفسك أول. اسأله أسئلة غريبة وشوف هل يألّف أجوبة.
  • قوانين واتساب: تقدر ترد بحرية خلال 24 ساعة من آخر رسالة للعميل. بعدها تحتاج قوالب (Templates) معتمدة.
  • المهارات لسا Alpha حسب Kapso، فممكن تتغير الأوامر. إذا أمر ما اشتغل، ارجع لصفحة المهارات تحت.
